# App de Gestión de Citas Médicas
## Análisis y Selección del Stack de Desarrollo

### Objetivo
Analizar diferentes tecnologías para desarrollar una aplicación móvil de gestión de citas médicas compatible con Android e iOS y seleccionar la más adecuada.

------------------------------------------------------

## Frameworks evaluados

### Flutter
- Lenguaje: Dart
- Ventajas:
  - Alto rendimiento
  - UI consistente
  - Amplia comunidad
- Desventajas:
  - Requiere aprender Dart

### React Native (Expo)
- Lenguaje: JavaScript/TypeScript
- Ventajas:
  - Gran ecosistema
  - Curva de aprendizaje baja
- Desventajas:
  - Dependencia del bridge JavaScript

### Kotlin Multiplatform
- Lenguaje: Kotlin
- Ventajas:
  - Código compartido
  - Excelente integración nativa
- Desventajas:
  - Mayor complejidad

------------------------------------------------------

## Comparativa

| Framework | Lenguaje | Rendimiento | Comunidad |
|------------|-----------|-------------|-----------|
| Flutter | Dart | Muy Alto | Alta |
| React Native | TypeScript | Alto | Muy Alta |
| Kotlin Multiplatform | Kotlin | Muy Alto | Media |

------------------------------------------------------

## Tecnología seleccionada

### Flutter + Dart

#### Justificación
- Desarrollo multiplataforma.
- Una única base de código.
- Excelente rendimiento.
- Menor costo de mantenimiento.
- Gran soporte comunitario.
